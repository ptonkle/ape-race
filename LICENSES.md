# Licences

The code is MIT ([LICENSE](LICENSE)). No third-party picture, model, font or sound ships: every ape, ship, tree and building is built from shapes in `crates/core`, the shaders are in `data/shaders/`, the map cards in `data/maps/` are screenshots of the game itself, and every sound is synthesized in the page from the core's sound list. Text uses the player's system fonts.

`web/vendor/trystero-nostr-0.25.4.js` is [Trystero](https://github.com/dmotz/trystero) by Dan Motzenbecker (MIT), bundled with its dependencies, and pinned by `web/vendor/SHA256SUMS`. `web/online.js` and `web/online-config.js` come from Mandible, ptonkle's other game (MIT).

The game was built on the [Builder template](https://github.com/sgilson7/builder-setting).
